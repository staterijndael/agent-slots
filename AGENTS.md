# Agent Slots: notes for agent sessions working on this repository

- What it is: `README.md` (Russian: `README.ru.md`; keep both in step). Why each rule exists: `docs/DESIGN.md`.
- Claude Code plugin: `.claude-plugin/` (plugin.json, marketplace.json, icon), `skills/`, `hooks/hooks.json`,
  `plugin/` (guard.py, session_start.py); `bin/` is on the agent's PATH when the plugin is enabled. Check with
  `claude plugin validate .`.
- Layout: `agent_slots/` (core.py scheduler and state, resources.py types and plugin loader, strategies.py,
  config.py, system.py memory and pid checks, cli.py), `tests/` (unittest, fake simctl), `examples/`, `bin/slots`,
  `docs/img/` (diagrams generated by `make.py`; edit the script, not the SVGs).
- Rules: standard library only, Python 3.9+ (macOS `/usr/bin/python3` is 3.9). Every behavior change gets a test
  in `tests/test_slots.py`; run `python3 -m unittest discover tests` before committing. A rule that comes from an
  incident gets a row in `docs/DESIGN.md`.
- Tests never touch `~/.agent-slots`; they set `SLOTS_HOME`, `SLOTS_CONFIG`, `SLOTS_SIMCTL` and fake memory.
- The machine's live config may point `canonical` at this checkout: every running agent re-executes it within one
  poll after you save a file here, so keep the working tree runnable.
